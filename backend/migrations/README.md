# Database Migrations

This directory contains Alembic database migrations for the CaseCite platform.

## Setup

1. Install dependencies:
   ```bash
   pip install alembic sqlalchemy asyncpg psycopg2-binary aiosqlite
   ```

2. Configure database URL:
   ```bash
   # Development (SQLite - default if not set)
   # No configuration needed - uses ./data/casecite.db

   # Production (PostgreSQL)
   export DATABASE_URL="postgresql+asyncpg://user:password@host:5432/casecite"
   ```

## Common Commands

### Generate a new migration (autogenerate from models)
```bash
cd backend
alembic revision --autogenerate -m "Add user table"
```

### Apply all pending migrations
```bash
alembic upgrade head
```

### Rollback one migration
```bash
alembic downgrade -1
```

### Rollback all migrations
```bash
alembic downgrade base
```

### View current revision
```bash
alembic current
```

### View migration history
```bash
alembic history
```

### Generate SQL without applying (for review)
```bash
alembic upgrade head --sql
```

## Migration Guidelines

1. **Always review autogenerated migrations** - Alembic's autogenerate is helpful but not perfect. Check for:
   - Dropped columns/tables that shouldn't be dropped
   - Index and constraint naming
   - Data migrations that might be needed

2. **Test migrations in development first** - Run `alembic upgrade head` and `alembic downgrade -1` to verify both directions work.

3. **Include data migrations when needed** - If you're changing column types or adding NOT NULL constraints, you may need to migrate existing data.

4. **Never edit a migration that's been deployed** - Create a new migration instead.
